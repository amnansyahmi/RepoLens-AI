# Contributing to RepoLensa AI

Thanks for helping! Please open an issue before substantial feature work, and avoid including any proprietary source code in issues or test fixtures.

## Setup

```bash
npm install
npm run dev
npm test
npm run build
```

Keep changes focused, add tests for analyzer logic, and submit a PR. Never include credentials, private repository code, or generated build output.

## Before submitting

Run `npm run typecheck`, `npm test` and `npm run build`. Include expected and actual behavior and a minimal synthetic reproduction. Redact private filenames, screenshots, URLs and tokens. Report security issues privately using [SECURITY.md](SECURITY.md).

Good first contributions include import fixtures, accessible graph controls, and documentation examples. See [the roadmap](docs/ROADMAP.md).
