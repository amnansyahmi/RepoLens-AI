# GitHub listing and profile checklist

The repository's **About** section and personal-profile pinned repositories are account-level GitHub settings. They are not configured by the source files in this repository.

## Recommended About section

**Description** (under GitHub's 160-character limit):

> Open-source codebase explorer: interactive dependency graphs, source-linked architecture health reports, and optional BYOK AI.

**Website:** https://repolensa-ai.vercel.app

**Topics** (enter one by one in the repository's About editor):

`developer-tools`, `code-analysis`, `dependency-graph`, `architecture-visualization`, `typescript`, `dotnet`, `react`, `open-source`, `github`, `byok`

**Social preview:** GitHub Settings → General → Social preview → Edit. Use an actual capture or a clearly labeled branded illustration. The editable vector illustration is [repolensa-cover.svg](assets/repolensa-cover.svg). A social preview typically looks best at 1280 × 640 pixels. Do not label illustrations as actual app screenshots.

## Pin RepoLensa on the GitHub profile

Open https://github.com/amnansyahmi → **Customize your pins** → select **RepoLensa-AI** → Save. Pinned repositories are part of the account profile and are not affected by README changes.
