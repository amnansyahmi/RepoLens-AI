# Changelog

## [1.1.0] — 2026-11-23

- RepoLensa working-name frontend brand while keeping the existing GitHub repository path
- Evidence-backed structural health report, five-dimension radar, language ring, source-linked findings and Markdown export
- Optional Gemini/OpenRouter BYOK with memory-only credentials, explicit metadata-sharing consent and provider-side rate-limit handling
- Security and methodology documentation for transparent report interpretation
- No backend or hosted-model running cost introduced; provider charges and quotas remain the visitor's responsibility

## [1.0.0] — 2026-11-23

- Public GitHub URL imports and local folder analysis, with privacy-first source handling and bounded requests
- Syntax-tree JS/TS import analysis and basic TypeScript path aliases
- C# project references and heuristic namespace relationships
- Interactive React Flow architecture visualization with file/directory views and directional layouts
- Architecture insights: cycles, hubs, isolated files, entrypoints and languages
- Export diagrams as SVG, PNG, Mermaid and JSON
- Optional Ollama-powered local architecture explanations without a cloud API key
- CI tests, security/contribution documentation, MIT license and Vercel static deployment support

**Known limitations:** semantic C# type resolution requires a future Roslyn analyzer. Public GitHub imports are limited to bounded source sets. Ollama requires a locally running compatible model, and browser CORS/private-network settings may prevent hosted pages from accessing it.
